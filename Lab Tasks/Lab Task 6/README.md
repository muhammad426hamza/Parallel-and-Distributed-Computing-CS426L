# Lab Task 6 – Java Map Collections

## Overview

This lab demonstrates how Java maps store student records and how maps can be used when multiple threads access shared data. The programs use basic Java concepts such as variables, loops, `if-else` statements, methods, `Scanner`, and `Runnable` tasks.

## Programs

### 1. `StudentMarks.java`

Uses a `HashMap<String, Integer>` to store student names and marks.

Features:
- Enter five initial student records.
- Add a student record.
- Display all student records.
- Update a student's marks.
- Search for a student's marks.
- Display the total number of students.
- Validate student names, marks, and menu input.

### 2. `SynchronizedStudentMap.java`

Uses `Collections.synchronizedMap()` to make a `HashMap` suitable for concurrent access.

Features:
- Uses an `ExecutorService` with three threads.
- Each thread inserts 100 unique student records.
- Displays the expected and actual number of entries.
- Uses `shutdown()` and `awaitTermination()` to wait for the tasks to finish.

**Expected entries:** 3 threads × 100 records = **300**.

### 3. `ConcurrentStudentMap.java`

Uses `ConcurrentHashMap` to manage student records with multiple threads.

Features:
- Uses an `ExecutorService` with five threads.
- Each thread inserts 1,000 unique student records.
- Retrieves values for the inserted keys.
- Displays the expected and actual number of entries.
- Measures execution time in milliseconds.

**Expected entries:** 5 threads × 1,000 records = **5,000**.

## Requirements

- Java Development Kit (JDK) installed
- A terminal or IDE such as Visual Studio Code

Check Java is installed by running:

```bash
java -version
javac -version
```

## Compile and Run

Open a terminal in the folder containing the Java files.

### Question 1

```bash
javac StudentMarks.java
java StudentMarks
```

### Question 2

```bash
javac SynchronizedStudentMap.java
java SynchronizedStudentMap
```

### Question 3

```bash
javac ConcurrentStudentMap.java
java ConcurrentStudentMap
```

Each program displays a menu. Enter the number of the operation you want to perform and follow the prompts.

## Concepts Practiced

- `HashMap` key-value pairs
- `Collections.synchronizedMap()`
- `ConcurrentHashMap`
- `Scanner` for keyboard input
- Loops and conditional statements
- Input validation
- `Runnable` and `ExecutorService`
- `shutdown()` and `awaitTermination()`
- Retrieving map values and counting entries
- Measuring execution time

## Notes

- The expected entry counts are 300 for Question 2 and 5,000 for Question 3.
- Execution time may differ across computers.
- The student records in Questions 2 and 3 are generated by the threads; they are not entered manually one by one.
